# webTerminal 需求点

- 浏览器 SSH 面板：连接后端服务节点。
- AI CLI 支持：适配 Claude Code、Codex CLI。
- 会话恢复：断开或刷新后重连原会话并回显数据。
- 浏览器保活：长时间打开不主动断连。
- 节点白名单：仅允许连接配置允许的节点和端口。
- 单用户认证：网站和 WSS 连接均需登录，失败过多锁定 IP。
- 认证安全通道：登录认证和 ws 业务帧采用短期非对称握手、对称加密、HMAC 加签和防重放校验。
- SSH 密码输入：连接页只填用户名，SSH 页面临时输入密码。
- 节点输入记忆：按节点 IP 记住上次端口和用户名。
- 后端配置：统一配置文件维护，支持环境变量注入。
- 前后端分界：前端和后端代码独立目录。
- 弱网输入缓冲：高延迟下连续输入不阻塞。
- 界面体验：美观、简洁、优雅。
- 资源占用：降低服务器和网页端开销。
- 技术与安全：使用稳定新技术并降低公网攻击面。
- 架构解耦：前后端独立，便于替换后端和扩展功能。
